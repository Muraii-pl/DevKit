DevKit

Uproszczona biblioteka klas narzędziowych CSS w stylu Tailwinda. Czysty CSS, warianty responsywne i wszystkie wartości konfigurowalne zmiennymi CSS.

1. Instalacja

Z GitHub Packages (potrzebny .npmrc z tokenem):

npm install @muraii-pl/devkit

albo prosto z repozytorium:

npm install github:Muraii-pl/DevKit

2. Dołączenie

@import "@muraii-pl/devkit";

Wersja zminifikowana: @muraii-pl/devkit/min.

3. Konfiguracja

:root {
  --color-primary: #7c3aed;
  --spacing: 0.3rem;
}

Pełna instrukcja: docs/configuration.md.

Motywy

Trzy motywy (default, warm, ocean), każdy w wersji jasnej i ciemnej. Włączasz je atrybutem data-theme na <html> albo na dowolnym fragmencie strony. Tryb ciemny dopisujesz jako drugie słowo. Całą stronę przełączysz w nawigacji. 

<html data-theme="dark">        <!-- default ciemny -->
<html data-theme="warm">        <!-- warm jasny -->
<html data-theme="ocean dark">  <!-- ocean ciemny -->
<div data-theme="light">       <!-- jasny fragment na ciemnej stronie -->

data-theme="ocean dark"

Ten fragment ma własny motyw niezależnie od reszty strony.

Kolory

Dla każdego tokenu --color-* są klasy text-*, bg-* i border-*, a także *-transparent i *-current. Role (primary, secondary, success, warning, danger) zmieniaj pod markę projektu.

Responsywność

Każda klasa ma warianty sm: (od 40rem), md: (48rem), lg: (64rem) i xl: (80rem). Działają od danej szerokości w górę (mobile-first). Zmień szerokość okna.
